# 学习日志使用说明

## 目录结构

```
journal/
├── README.md        # 本文件：记录规范 + 复习机制
├── index.md         # 总览表：所有日期的进度/分数/困惑，一眼看趋势
└── daily/           # 每日一篇：2026-10-15.md 这种命名
```

## 每日记录规范

在 `daily/` 下新建当天日期的 md 文件，五块内容，2 分钟填完：

1. **进度**：今天学到第几课，讲到什么主题
2. **困惑记录**：没搞懂/没独立做出的题，写清困惑点是什么（这一栏是复习的弹药库，越具体越好）
3. **重点题目**：当天遇到的核心模板题/好题（不是不会，是值得周期性重做的那种），标记出来
4. **自评打分**（0~10，统一锚点，避免分数通胀）：
   - 9~10：全懂 + 独立 AC + 能讲给别人
   - 7~8：看懂讲解，题能跟着写出来
   - 5~6：大致理解，题没独立写出
   - ≤4：云里雾里（重要复习信号）
5. **明日计划**：一两句话即可

## 复习机制（针对性复习怎么落地）

- **每天**：困惑记录里新添的题标记 `❓待解决`
- **每周末**：集中清掉一批——重看 PPT / 手推代码 / 问 AI，弄懂后改 `✅已解决` 并补一行"当时卡在哪、现在怎么理解的"
- **每月底**：把当月所有出现过的**困惑题和重点题各重做一遍**（不看旧代码、用对数器自测），确认是真懂了
- **随时**：翻 `index.md`，分数连续走低或某类题反复困惑（比如都是树上的题），就说明该回去补对应专题了

## 附：用 git 历史反推每天学到哪课

提交记录能自动统计某天学了哪些 class，填日志时不用回忆：

```bash
# 某天改动过的课程目录
git log --since="2026-10-14 00:00" --until="2026-10-15 00:00" --name-only --format="" | grep -o 'class[0-9]*' | sort -u
```
